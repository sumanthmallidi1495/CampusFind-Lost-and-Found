CampusFind – College Lost and Found Management System

Project Description

CampusFind is a Python-based College Lost and Found Management System developed using Tkinter.

It helps students report lost and found items on campus and makes it easier to identify and recover belongings.

Features

- Report lost items.
- Report found items.
- Upload item images.
- Browse and search reported items.
- Filter items by category and status.
- Mark reports as resolved.
- View item details.
- Suggest possible matches between lost and found items.
- Dashboard showing report statistics.

Technologies Used

- Python
- Tkinter
- Pillow (for image handling)

How to Run

1. Install Python.
2. Install Pillow using "python -m pip install pillow".
3. Download the Python file.
4. Run "python CampusFind_updated.py".
